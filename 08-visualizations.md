# Visualization Index

The wiki uses multiple visualization types because no single diagram captures both the social model and the repository structure.

| Visualization | Type | Answers |
|---|---|---|
| System map | Conceptual architecture | What is the overall system and where does the repository fit? |
| Concept map | Mind map | How do intent, principles, protocol, action, and replication relate? |
| Architecture | Layered architecture | Which responsibilities are centralized, and which remain local? |
| Actor interaction | Relationship graph | Who can give, ask, connect, help, or start? |
| Lifecycle flow | Flowchart | What is the canonical participation loop? |
| Request sequence | Sequence diagram | How can a request move from need to result? |
| State machine | State diagram | What states can an interaction pass through? |
| Launch sequence | Flowchart | How can a new community start with minimal machinery? |
| Governance model | Relationship graph | How do local communities, forks, and the reference repository relate? |

All diagrams have editable Mermaid source in `diagrams/` and rendered PNG versions in `assets/`. The Markdown pages also describe the limits of each model so that diagrams are not mistaken for undocumented software behavior.
